# Protocol 1.0 golden examples

These are manually specified, public synthetic contract examples, not captured
account traffic or output generated by the serializer under test. Stable IDs and
timestamps support future Swift decoding tests. Individual events illustrate
shapes; their sequence numbers do not form a single replayable transcript.

Hello request/response and ready define the implemented capabilities. Analysis
requests cover URL, text search and exact Watch Later keyword. Items use a
non-routable sanitized display URL; enqueue must use the retained source_id.
Progress and error examples contain no headers, private paths or credentials.
See tests/test_backend_fixtures.py for independent adapter comparisons.
