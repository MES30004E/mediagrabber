MediaGrabber
Local-only UI No cookies requested No analytics No backend

Resolve Instagram media without handing your session to another site.

Paste an Instagram URL, open it in your own logged-in Instagram tab, then use the one-click capture bookmark. The media links are returned here and rendered as a private result library in your browser.

Nothing is uploaded from this form.
Important: a static GitHub Pages site cannot read your Instagram login cookies. That browser boundary is intentional. The capture bookmark runs on instagram.com and only returns already-loaded media URLs.

Privacy model

Your login stays with InstagramNo session cookie, CSRF token, password, or Authorization header is requested by this page.
No application serverThe page is static HTML/CSS/JavaScript. There is no resolver API behind it.
Results are ephemeralCaptured URLs are kept in the current tab only. They are not stored in localStorage.
Signed links expireInstagram CDN links are temporary. Open or save them soon after capture.

One-time setup

Install the capture bookmark once, then reuse it on stories, reels, posts, and carousels.

1

Add the bookmark

Drag MG Capture below to your bookmarks bar. If dragging does not work, use Copy and create a bookmark manually.

MG Capture
2

Open the media in Instagram

Use the URL box above. Make sure the story, reel, post, or carousel is actually visible and loaded in your logged-in tab.

3

Click MG Capture

The bookmark scans loaded <video>, <img>, and Instagram CDN resources, then opens this page with a result library.

Advanced fallback: paste an Instagram GraphQL JSON response

Parsing is local. Do not paste cookies, request headers, passwords, or session tokens.
